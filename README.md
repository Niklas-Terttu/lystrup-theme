# Lystrup Theme

WordPress-tema til Lystrup Borgerforening, version 0.1.0.

Temaet indeholder forside, navigation, responsivt design og oprettelse af sider ved aktivering. Portalerne og registreringen kræver det separate **lystrup-plugin**.

**Udviklingsversion:** Ikke klar til fortrolige oplysninger. Beskyttelse af hele private sider og filer skal implementeres og testes inden produktion.
